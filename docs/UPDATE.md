# به‌روزرسانی داشبورد — چه چیزی دستی است و چه چیزی نه

## آیا خودش آپدیت می‌شود؟

**نه.** `portfolio.html` یک فایل ثابت است که از یک عکس لحظه‌ای ساخته می‌شود.
اگر فردا بازش کنید، اعداد همان روز ساخت است.

سه چیز را با هم اشتباه نگیرید:

| فایل | چه می‌کند |
|---|---|
| `app/dash.html` | **زنده** — هر ۳۰ ثانیه از TSETMC می‌خواند. بک‌تست ندارد. |
| `dashboard_monthly.html` | عکس لحظه‌ای؛ با اجرای `dashboard_monthly.py` ساخته می‌شود |
| `portfolio.html` | از فایل بالا ساخته می‌شود؛ خودش هیچ‌جا وصل نیست |

## دستور به‌روزرسانی

```powershell
python dashboard_monthly.py
python tools\portfolio_dashboard.py --in dashboard_monthly.html --out portfolio.html --capital 124340025875
```

یا `tools\refresh.bat` را کنار `dashboard_monthly.py` بگذارید و اجرا کنید:

```powershell
tools\refresh.bat 124340025875
```

## کِی اجرا کنید

صندوق‌های طلا و نقره حدود ساعت ۱۸ کلوز می‌دهند. قبل از آن، ستون «ریسک جاری»
برای آن‌ها ناقص است. برای تصمیم ماهانه، **آخرین روز معاملاتی ماه میلادی بعد
از ۱۸** اجرا کنید.

## اگر واقعاً خودکار بخواهید

یک Routine روزانه که بعد از بستن بازار اجرا شود شدنی است، ولی باید **روی
کامپیوتر خودتان** بنشیند، نه اینجا: منابع دادهٔ ایرانی از کانتینر ابری در
دسترس نیستند (TSETMC، چارتیکس، BrsApi و کدال همه `HTTP 000` می‌دهند). یک
Task Scheduler ویندوز که `refresh.bat` را هر روز ساعت ۱۸:۳۰ اجرا کند،
همین کار را می‌کند.
