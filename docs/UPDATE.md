# به‌روزرسانی — یک دستور

```
python bourse.py
```

این فایل قبلاً یک زنجیرهٔ چندمرحله‌ای را توضیح می‌داد. آن زنجیره دیگر
لازم نیست و توضیحش اینجا فقط گمراه‌کننده بود. `bourse.py` همهٔ آن
مراحل را خودش انجام می‌دهد و `dashboard.html` را می‌سازد و باز می‌کند.

جزئیات و سوییچ‌ها: بالای `README.md`.

---

## سه چیزی که قبلاً با هم قاطی می‌شد

| فایل | چه بود |
|---|---|
| `app/dash.html` | زنده، هر ۳۰ ثانیه از TSETMC — بک‌تست نداشت |
| `dashboard_monthly.html` | عکسِ لحظه‌ای، دستی ساخته می‌شد |
| `portfolio.html` | از فایلِ بالا ساخته می‌شد، خودش به جایی وصل نبود |

هر سه را **`dashboard.html`** جایگزین کرده: هم دادهٔ روز، هم بک‌تست،
هم دفترِ پیشنهادی، هم آلارم، در یک صفحه.

## آیا خودش هر روز اجرا می‌شود؟

نه. باید دستور را بزنی. اگر خودکار می‌خواهی، در Task Scheduler ویندوز
یک تسکِ روزانه بساز که همین یک خط را اجرا کند — ساعتِ درستش **۸:۳۰
صبح** است، قبل از پیش‌گشایشِ ۸:۴۵ (بند ۲ راهنما).
