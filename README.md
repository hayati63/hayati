# hayati

بازبینی و ابزار بک‌تست استراتژی باکس حجمی (Volume Profile Fixed Range) برای
صندوق‌های ETF بورس ایران.

---

# 🟢 هر روز صبح فقط همین یک دستور

```
python bourse.py
```

همین. نه نصبی، نه کتابخانه‌ای، نه مرحلهٔ دوم. `bourse.py` خودش:

۱. نمادها را از دیدبانِ TSETMC پیدا می‌کند
۲. تاریخچه را دانلود می‌کند (توی `data_bourse/`)
۳. باکسِ ماهانه، هفتگی و خلای حجمی را می‌سازد
۴. دفترِ پیشنهادی و آلارمِ خرید/فروش را حساب می‌کند
۵. `dashboard.html` را می‌سازد و **خودش در مرورگر باز می‌کند**

اولین اجرا چند دقیقه طول می‌کشد (تاریخچهٔ ~۱۳۰ نماد). بعدش سریع است.

### پیش‌نیاز

فقط **پایتون ۳٫۸ یا بالاتر**. هیچ `pip install`ی لازم نیست — کلِ فایل
با کتابخانهٔ استانداردِ خودِ پایتون نوشته شده.

⚠️ باید از ماشینِ خودت اجرا شود، نه از کانتینرِ ابری: TSETMC از آنجا
۴۰۳ می‌دهد (بند ۵ راهنما).

### سرمایه

اگر چیزی ندهی، خودش از پرتفو حساب می‌کند (ارزشِ روزِ نمادها + نقدِ بند
۷ راهنما) و عدد را در `data_bourse/capital.txt` می‌نویسد. برای عوض
کردنش یکی از این دو:

```
python bourse.py --capital 105000000000
```

یا عدد را مستقیم در `data_bourse/capital.txt` بنویس.

### چند سوییچ که به درد می‌خورند

| سوییچ | کار |
|---|---|
| `--offline` | دانلود نکن، از دادهٔ دیروز بساز |
| `--no-open` | مرورگر را باز نکن |
| `--no-ticks` | ریزمعاملات را نگیر؛ سریع‌تر، ولی ۴۰٪ نماد باکسِ ضعیف‌تر می‌گیرند |
| `--telegram` | آلارم را به تلگرام بفرست (`TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` لازم است) |
| `--probe` | اگر دانلود نگرفت، منابع را تست کن و گزارش بده |

اگر پارسر خطا داد، `python bourse.py --probe` را بزن و خروجی‌اش را
بفرست — کلید را ماسک می‌کند، پس امن است.

## 🔵 سهام — داشبوردِ جدا

```
python bourse.py --stocks
```

جهانِ کاملاً جدا: دادهٔ جدا (`data_stocks/`)، خروجیِ جدا
(`dashboard_stocks.html`)، و **جدولِ نرخِ بردی که از خودِ سهام ساخته
می‌شود**، نه از صندوق‌ها. کنارِ هر سطر p می‌آید، پس معلوم است کدام
وضعیت از نرخ پایه جدا شده و کدام نه.

⚠️ **کارمزدِ سهام ~۱٫۲٪ رفت‌وبرگشت است، بیش از دو برابرِ صندوق.** بند ۹
راهنما: «مزیت روی صندوقِ اهرمی محکم است و روی سهام نازک.» ستونِ بازده
**ناخالص** است — هر سطری که مزیتش زیرِ ۱٫۲ واحد باشد، بعد از کارمزد
چیزی ازش نمی‌ماند. داشبورد خودش این را بالای صفحه می‌نویسد.

| سوییچ | کار |
|---|---|
| `--min-value 300` | حدِ ارزشِ معاملاتِ روزانه (میلیارد ریال)؛ پیش‌فرض ۵۰۰ |
| `--iters 5000` | تکرارِ آزمونِ جایگشت؛ بیشتر = p دقیق‌تر، کندتر |

اجرای اول سنگین است (دانلودِ تاریخچه + بک‌تست). دو پوشه هیچ‌وقت قاطی
نمی‌شوند: اگر فایلِ صندوقی در `data_stocks/` جا بماند، نادیده گرفته
می‌شود و تعدادش چاپ می‌شود.

### پرتفو کجاست

داخلِ خودِ `bourse.py`، بالای فایل: `HOLDING` و `CASH`. وقتی پرتفو
عوض شد همان‌جا را دست بزن.

### دو پنجره، دو معنی

یک نکته که تا آخر پروژه گم بود و حالا هر دو سرش اندازه گرفته شده:

| | باکس از | بازده اندازه‌گرفته‌شده | کجا دیده می‌شود |
|---|---|---|---|
| **پنجرهٔ ۱** | ماه **قبلِ** کامل‌شده | کل ماه بعد | ستون «وضعیت ماه قبل» |
| **پنجرهٔ ۲** | **همین ماه تا امروز** | از امروز تا پایان همین ماه | چراغ زندهٔ داشبورد |

این دو می‌توانند هم‌زمان خلاف هم بگویند و تناقض نیست. `monthly_backtest.py`
پنجرهٔ ۱ را می‌سنجد و `intramonth_test.py` پنجرهٔ ۲ را.

`portfolio_dashboard.py` چهار آرایهٔ جاسازی‌شدهٔ `dashboard_monthly.html` را
بیرون می‌کشد (TODAY، TRADES، SUMMARY، SIGNALS) و با همان تم، ده تب می‌سازد:
محرک‌ها، پرتفوی من، تصمیم امروز، پرتفوی هدف، تراز پرتفو، **شواهد**، بک‌تست،
همبستگی دسته‌ها، همهٔ نمادها، سلامت داده. سرمایه، وزن عامل‌ها، تعداد پوزیشن،
کف استاپ و سقف وزن در خود صفحه تنظیم می‌شوند. تب «شواهد» را از
`data/evidence_month.json` و `data/evidence_intramonth.json` می‌خواند و ستون
نقدشوندگی را از `data/liquidity.json` — اگر نبودند، تب می‌گوید چه دستوری را
اجرا کنید.

`snapshot_dashboard.py` خروجی متنی `export_monthly_risk.py` را می‌خواند و
صفحهٔ تصمیم + پرتفو می‌سازد: سایز هر پوزیشن از روی فاصله تا کف باکس، با
`--top`، `--total-risk` و `--capital`. بک‌تست ندارد — ورودی‌اش عکس لحظه‌ای
است، نه سری زمانی.

`build_dashboard.py` همان تحلیل را در یک صفحهٔ HTML خودکفا می‌ریزد. با
`--artifact` اسکلت `html/head/body` را حذف می‌کند تا مستقیم روی claude.ai
منتشر شود، و `--note` یک بنر بالای صفحه می‌گذارد.

`--data` پوشهٔ CSVهای روزانه است (خروجی `algotik_tse` یا BrsApi). ستون تاریخ و
`close` لازم است؛ `high`/`low`/`volume` اگر باشند استفاده می‌شوند.

### به‌روزرسانی روزانه — چرا روی ماشین شما و نه اینجا

دروازهٔ شبکهٔ کانتینر ابری به `cdn.tsetmc.com` و `max.chartix.ir` جواب **۴۰۳**
می‌دهد. این منعِ سیاست است، نه خطای DNS یا TLS — هیچ کلید و لاگینی عوضش
نمی‌کند. ولی از ویندوزِ خودتان کار می‌کند (بند ۵ `CLAUDE.md`).

و بین دو منبع، **چارتیکس خودکارشدنی نیست**: فیدش سوکتی است، پس خودکارسازی‌اش
یعنی شبیه‌سازی مرورگر. TSETMC یک GET ساده است و **کل تاریخچه** را می‌دهد، نه
۱۵۰ کندل — همان چیزی که بک‌تست منظم لازم دارد.

```bash
python tools/fetch_tsetmc.py --discover   # یک‌بار: فهرست کامل نماد→insCode
refresh.bat                               # هر روز: دانلود + محاسبه + گیت
```

زمان‌بندی خودکار روی ویندوز، هر روز ۱۸:۳۰ (بعد از کلوز طلا و نقره):

```
schtasks /create /tn "hayati-daily" /tr "C:\path\to\hayati\refresh.bat" /sc daily /st 18:30
```

`data/symbols.csv` با ۱۷ نمادِ `CLAUDE.md` بند ۵ پر شده تا بدون `--discover`
هم بشود شروع کرد.

⚠️ `fetch_tsetmc.py` در این کانتینر **در برابر API واقعی تست نشده** — شبکه‌اش
بسته است. پارسرش آفلاین تست شده (`tools/test_fetch_tsetmc.py`) و هر پاسخ
نامنتظر را با کلیدهای واقعی‌اش چاپ می‌کند به‌جای اینکه بی‌صدا رد شود.

### بررسی صفحهٔ تولیدشده

این صفحه‌ها یک رشتهٔ چندهزارخطی جاوااسکریپت‌اند که از پایتون بیرون می‌آیند. یک
بک‌تیکِ نبسته یا یک فیلدِ نبودهٔ JSON صفحه را سفید می‌کند، بدون اینکه هیچ ابزار
پایتونی خبردار شود — `ast.parse` فقط می‌گوید پایتون درست است، نه اینکه صفحه
بالا می‌آید. این اسکریپت واقعاً صفحه را با یک DOM حداقلی اجرا می‌کند:

```bash
node tools/render_check.js portfolio.html     --want "اولین دره" --want "کنترل افق"
```

سه چیز را می‌سنجد: خطای زمان اجرا، پنلی که ساخته نشد، و `undefined`/`NaN` در
خروجی. `--want` برای وقتی است که می‌خواهید مطمئن شوید یک پنل با **دادهٔ
واقعی** پر شده، نه با پیام «فایل نیست».

وابستگی ندارد — فقط کتابخانهٔ استاندارد پایتون ۳.

## آنچه این ابزار متفاوت انجام می‌دهد

بک‌تست‌های قبلی نرخ برد را بدون **نرخ پایه** گزارش می‌کردند. در بازاری که ماه
قبل ۹۸٫۶٪ نمادها بالای باکسشان بسته‌اند، «۷۷٫۹٪ برد» احتمالاً خودِ نرخ پایه است.

سه چیز اضافه می‌کند:

- **نرخ پایه** کنار هر عدد شرطی
- **تست جایگشت** — برچسب سیگنال داخل هر ماه به‌هم می‌ریزد، پس حرکت کل بازار
  خنثی می‌شود. با ۱۴۵ نماد همبسته روی ۶ ماه، t معمولی چند برابر بزرگ‌تر از
  واقعیت درمی‌آید
- **هندسهٔ ۱:۱** خود `CLAUDE.md` (ورود روی پولبک، نرخ «حمایت خالی»)

کف p برابر `۱/(تکرار+۱)` است، نه تابع تعداد ماه: برچسب داخل هر ماه جابه‌جا
می‌شود و هر ماه ده‌ها نماد دارد. آنچه تعداد ماه محدود می‌کند **تعمیم‌پذیری**
است — ۹ ماه یک رژیم بازار است، نه همهٔ رژیم‌ها.
