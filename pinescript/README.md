# کدهای TradingView

کد Pine Script اصلی اینجا نگه داشته می‌شود تا نسخهٔ MQL5 در برابرش قابل بررسی باشد.

- `lvn_clarity_cascade.pine` — ✅ دریافت شد، به MQL5 منتقل شد
- استراتژی بورس — ⏳ هنوز نرسیده

کد را در چت پیست کنید؛ همین‌جا ذخیره و ترجمه می‌شود. اگر نسخه‌های مختلفی دارید،
همان نسخه‌ای را بفرستید که بک‌تست MT5 از رویش گرفته شده — تا بشود اعداد را مقایسه کرد.
